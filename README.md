# The Meeting That Should Have Been an Email

One line. One joke. No setup needed:

> Someone shared their screen to show us an email we could have just read.

## How to run

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```

This writes the line above to `$MAKEFUN_OUTPUT_DIR/entry.txt` — exactly one
line, 1–200 characters, no trailing newline.
